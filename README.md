# Growl - Personal Growth Social Platform

A social platform designed to help people improve by scrolling through interest-based content, connecting with instructors, and accessing curated marketplace products.

## Project Structure

```
growl_rn_ts_twrnc_sdk54_v5/
├── frontend/          # React Native mobile app
├── backend/           # Backend architecture & API docs
└── admin/             # Admin dashboard documentation
```

## Quick Start

### Frontend
```bash
cd frontend
npm install
npm start
```

### Backend
See `backend/README.md` for setup instructions.

### Admin
See `admin/README.md` for admin dashboard planning.

## Features

- **Personalized Feed**: Content based on user interests and metadata
- **Reels**: Vertical video content feed
- **Instructor System**: Community-voted instructors with student management
- **Business Dashboard**: Complete business management tools
- **Marketplace**: Product recommendations with promotion system
- **Messages & Stories**: Social interaction features

## Tech Stack

### Frontend
- React Native (Expo SDK 54)
- TypeScript
- Tailwind CSS
- React Navigation
- Zustand & Redux Toolkit

### Backend (Planned)
- Cloudflare Workers
- Cloudflare D1 (SQLite)
- Cloudflare R2 (Object Storage)
- Cloudflare Auth
